# Al Harfiyyin (الحرفيين)

A platform connecting craftsmen and service providers with clients.

## Features

- User registration and authentication
- Service provider profiles and portfolios
- Service listings and categories
- Client project posting
- Messaging system between clients and service providers
- Rating and review system

## Installation

1. Clone the repository
2. Configure your web server to point to the project directory
3. Import the database schema
4. Configure the database connection in `includes/config.php`
5. Run `create_upload_dirs.php` to set up required directories

## Requirements

- PHP 7.0+
- MySQL/MariaDB
- Modern web browser
